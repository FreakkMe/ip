# AI Usage Log – Freaky Project
- AI Tool Used : ChatGPT (OpenAI)

- Usage Period: Entire project duration (Increment A to final submission)

- Purpose: AI-assisted development, debugging, refactoring, documentation, 
and workflow guidance

---

## Overview

This project was developed with AI-assisted support mainly using ChatGPT. 
AI was used as a development assistant to improve productivity, clarify technical 
concepts, debug issues, and refactor code where necessary.

All AI-generated suggestions were reviewed, tested, and manually integrated into 
the project.

---

## Areas Where AI Was Used
### 1. Refactoring Core Logic

- When transitioning from console-style output to return-based message handling:

- Refactored methods to return String instead of printing directly.

- Improved separation of concerns between core logic and UI.

- Simplified validation and error handling flow.

**Impact:** Improved architecture clarity and reduced debugging time.


### 2. JavaDoc Generation

- Generated JavaDoc comments for methods and classes.

- Improved method structure and naming.

- Interpreted and resolved Checkstyle errors.

**Impact:** Improved readability and maintainability of the codebase.

### 3. Streams Refactoring

- Integrated stream usage into check feature to reduce robustness of the code.

- Assisted with filtering and formatting collections.

**Impact:** Reduced verbosity and improved expressiveness of collection handling.

### 4. JavaFX Integration

- Debugged layout and resizing issues.

**Impact:** Significantly reduced setup and debugging time for GUI integration.

### 5. General Debugging

- Assisted in debugging logical errors.

- Explained error messages and stack traces.

- Provided structured reasoning when resolving issues.

**Impact:** Reduced time spent isolating and diagnosing bugs.

## Observations
What Worked Well

- Quick debugging assistance

- Helpful JavaFX workflow guidance

## Limitations

- Some suggestions required manual adjustment.

## Estimated Time Saved

Approximately 20–30 hours across the entire project, especially in:

- JavaFX setup

- Debugging complex issues

- Documentation writing

- Refactoring large method

---

## Conclusion

AI was used as a development assistant rather than a full code generator.
All design decisions and final implementations were manually reviewed and validated.

The hybrid workflow of human reasoning + AI-assisted refinement significantly 
improved productivity while maintaining understanding of the system’s architecture.
